All-in-One AI Product Description Generator

Generate engaging, HTML-formatted product descriptions effortlessly using top AI models.

Key Features

  • Multi-Provider Support: Generate text using OpenAI (ChatGPT), Google Gemini, Groq (Llama 3), or Anthropic Claude.
  • Tone Selection: Choose between Professional, Catchy, Casual, or Technical tones to match your brand.
  • HTML Formatting: Seamlessly injects clean HTML with bullet points directly into your product's Sales Description or Internal Notes.
  • Easy Configuration: Securely store your API keys and select models directly from Odoo General Settings.

How to Use

1. Configure API Keys: Navigate to Settings > General Settings. Under the "AI Product Description" section, select your preferred provider and input your API Key.

2. Open a Product: Go to your Products menu, open any Product Template, and click the Generate AI Description button in the header.

3. Generate: Enter keywords (e.g. "100% cotton, breathable, summer wear"), select your tone, and click Generate & Apply.
